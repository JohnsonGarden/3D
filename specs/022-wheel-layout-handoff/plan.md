# 022 architecture and design

The measured wheel station layout is an optional guardian-entered artifact. A pure helper validates longitudinal axle-center offsets relative to the front of the physical toy body, tire count, and optional tire diameter. An isolated React form creates an explicit local JSON download, with no network request or IndexedDB change.

The UI is only shown with a selected GLB, photos and valid physical dimensions. Changing photos or the selected GLB resets the form. No geometry rigging, inferred wheel placement, or change to legacy play-world scaling is implied.

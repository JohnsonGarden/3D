# 022 — Manual wheel station handoff

FR-001 Given a selected imported model and valid toy dimensions, when a guardian enters measured axle positions, then show a local review form.

FR-002 Given invalid offsets, when exporting, then reject out-of-order or out-of-body axle positions and impossible tire counts.

FR-003 Given valid manual measurements, when the user explicitly exports, then download metadata-only JSON without photos, model bytes, or URLs.

FR-004 Given a model or photo change, when revisiting the form, then clear the session-only values. Do not modify driving geometry or claim automated wheel recognition.

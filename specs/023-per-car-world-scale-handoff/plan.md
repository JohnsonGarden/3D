# 023 architecture and design

The browser computes a per-car uniform scaling proposal from guardian-entered toy dimensions and wheel stations. It does not apply transforms to stored models or driving physics.

Use one conversion factor based on explicitly chosen target body width. All measured lengths and offsets use that factor. Negative local Z points forward from body centre.

A pure module provides deterministic numbers, while the existing wheel form displays and exports an optional session-only result. No new dependencies or network access. Physical fidelity and Mac Safari checks remain manual.
